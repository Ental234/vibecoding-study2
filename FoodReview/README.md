# FoodReview

**다녀온 맛집에 리뷰를 남기고, 다른 사람의 리뷰로 다음에 갈 곳을 고르는 맛집 리뷰 서비스.**

검색해서 나오는 리뷰 대부분이 광고이거나 협찬이라 믿기 어렵고, 내가 다녀온 곳의 기록은
카톡·인스타·캡처 폴더에 흩어져 다시 찾을 수 없습니다. 별점 + 한 줄 + 사진 한 장으로
30초 안에 남기고, 태그·지역·별점으로 다시 찾을 수 있게 만드는 것이 목표입니다.

> 바이브 코딩 실습 프로젝트입니다. 사업적 성공이 아니라 **배포된 URL에서 실제로 동작하는 것**이 완료 기준입니다.

## 실행

지금은 정적 HTML 한 장이라 서버가 필요 없습니다.

```bash
git clone https://github.com/Ental234/FoodReview.git
cd FoodReview
# index.html 을 브라우저로 열면 끝
```

`index.html`은 Tailwind Play CDN을 쓰는 **디자인 검증용 목업**입니다.
콘솔에 `cdn.tailwindcss.com should not be used in production` 경고가 뜨는 것은 정상이며,
M1에서 Next.js `app/page.tsx`로 옮기면서 정식 빌드로 바뀝니다.

## 디자인

한 문장 컨셉은 **"크림색 종이 위에 노란 견출지를 붙이고 형광펜을 긋는다"** 입니다.

카카오 옐로우(`#F7E600`)는 크림 배경 대비가 1.2:1이라 글씨나 얇은 선으로 쓸 수 없습니다.
그래서 **노란 면에는 반드시 먹색 윤곽선을 두른다**는 규칙을 세웠고, 이 규칙이
별점 · 지도 핀 · 선택된 태그 · 주요 버튼에 반복 적용되면서 앱 전체의 시그니처가 됩니다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `paper` | `#FAF7F2` | 배경 (크림) |
| `ink` | `#1A1815` | 본문·윤곽선 (먹색) |
| `brand` | `#F7E600` | 카카오 옐로우 — 면을 채우는 색 |

폰트는 본문 **Pretendard**, 제목 **Gaegu**(손글씨). 손글씨는 가게명과 화면 제목처럼 짧은 곳에만 씁니다.
