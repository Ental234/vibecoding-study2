# 지금, 그곳 — DESIGN.md

이 문서는 Project Hub의 `DESIGN.md`를 상속합니다. 색상·폰트·카드 규칙은 허브와 동일하고,
이 프로젝트에만 있는 것(배경 테마 10종, 마커, 상세 카드)을 여기서 추가로 정의합니다.

---

## 1. 전체 무드

- 허브와 같은 **웜 차콜 배경 + 테라코타 포인트**
- 화면의 주인공은 지도이고, UI는 지도 위에 최소한으로 얹힙니다
- 장소를 고를 때마다 **배경만** 바뀝니다. 텍스트·카드 색은 그대로 두어 톤이 흔들리지 않게 합니다

---

## 2. 색상 (허브에서 그대로 가져옴)

| 용도 | 색상 코드 | 비고 |
|---|---|---|
| 배경색 | `#1A1815` | 웜 차콜 |
| 카드 배경 | `#232019` | 패널·상세 카드는 여기에 투명도를 얹어 씀 |
| 카드 배경(hover) | `#2A261E` | |
| 기본 텍스트 | `#F0EDE7` | |
| 보조 텍스트 | `#8A857E` | |
| 포인트 색상 | `#D98A66` | 마커, 선택 강조, 버튼 |
| 포인트 색상(hover) | `#C97B5A` | |
| 테두리/구분선 | `#302B24` | |

> ⚠️ 포인트 색(`#D98A66`) 위에는 **흰 글씨를 쓰지 않습니다.** 대비가 2.9:1까지 떨어집니다.
> 대신 배경색(`#1A1815`)을 글씨색으로 씁니다 (6.4:1). 날씨 칩이 선택됐을 때와 버튼이 이 규칙을 따릅니다.

패널과 상세 카드는 배경이 계속 바뀌므로 **반투명 + 블러**로 처리합니다.
`rgba(35,32,25,0.88~0.92)` + `backdrop-filter: blur(8~10px)` — 배경 날씨가 은은히 비치지만 글씨는 또렷합니다.

## 3. 글씨

허브와 동일한 시스템 폰트 스택을 씁니다.

```
-apple-system, BlinkMacSystemFont, "Segoe UI", "Pretendard", "Noto Sans KR", sans-serif
```

| 용도 | 크기 | 굵기 |
|---|---|---|
| 페이지 타이틀 | 24~32px | 700 |
| 상세 카드 기온 | 40px | 700 |
| 리스트 항목명 | 15px | 500 |
| 보조 설명·국가명 | 12~13px | 400 |
| 섹션 라벨(대문자) | 11px, 자간 0.16em | 400 |

숫자(기온·습도·풍속)에는 `font-variant-numeric: tabular-nums`를 줍니다.
값이 바뀔 때 자릿수가 흔들리지 않습니다.

## 4. 배경 테마 10종 (이 프로젝트의 핵심)

**날씨 5종 × 낮/밤 2종 = 10종.** 모두 CSS 그라디언트로만 만듭니다. 이미지 파일이 없어 즉시 전환됩니다.

구조는 전부 같습니다: **어두운 베이스 색 위에 라디얼 글로우 2겹.**
글로우 alpha는 0.09~0.85 사이로 제한해서, 어떤 테마에서도 `#F0EDE7` 텍스트 대비가 4.5:1 아래로 내려가지 않게 합니다.

| 날씨 | 낮 | 밤 |
|---|---|---|
| 맑음 | 앰버 글로우 `rgba(217,138,102,0.18)` / 베이스 `#1A1815` | 더스크 네이비 `rgba(25,26,62,0.85)` / 베이스 `#151317` |
| 흐림 | 웜 그레이 `rgba(163,155,143,0.16)` / `#1A1815` | 저채도 슬레이트 `rgba(58,64,76,0.55)` / `#16161A` |
| 비 | 머디 틸 `rgba(64,116,116,0.20)` / `#171A1A` | 딥 틸 `rgba(18,52,58,0.75)` / `#121618` |
| 눈 | 콜드 오프화이트 `rgba(214,224,232,0.16)` / `#191A1C` | 페일 블루그레이 `rgba(70,88,112,0.50)` / `#141619` |
| 뇌우 | 다크 바이올렛 `rgba(78,60,110,0.45)` + 상단 섬광 띠 / `#17141A` | 딥 인디고 `rgba(38,34,78,0.80)` / `#111018` |

> 💡 밤 테마의 글로우 alpha가 낮 테마보다 훨씬 높은 이유: 밤 색(네이비·틸·인디고)은 베이스 차콜과 밝기가
> 비슷해서 옅게 깔면 아예 안 보입니다. 반대로 낮 테마의 밝은 색은 조금만 얹어도 충분히 보이고,
> 진하게 얹으면 텍스트 대비가 무너집니다.

### 전환 방식

배경은 `.bg__layer` **두 장**을 겹쳐 두고 번갈아 씁니다.

1. 지금 안 보이는 뒤쪽 레이어에 새 테마 클래스를 칠하고
2. 뒤쪽을 `opacity: 1`, 앞쪽을 `opacity: 0`으로 동시에 바꿉니다 (0.6초 ease)

한 장짜리 배경을 바꾸면 중간에 색이 튀지만, 두 장을 교차시키면 부드럽게 넘어갑니다.
날씨를 불러오는 동안에도 **이전 배경이 그대로 남아 있습니다.**

## 5. 지도와 마커

- 타일: CARTO `dark_all`(Dark Matter). 웜 차콜 UI와 명도가 맞는 유일한 무료 다크 타일입니다
- 지도 컨테이너는 카드와 같은 규칙 — radius 12px, 테두리 `#302B24`

| 마커 | 모양 | 쓰임 |
|---|---|---|
| 랜드마크 | 지름 16px 테라코타 원 + 배경색 테두리 2px | 사전 정의된 12곳 |
| 검색으로 추가된 위치 | 같은 크기의 **속 빈 원 + 점선 테두리**(오프화이트) | 검색해서 찍은 임시 위치 |
| 선택됨 | 1.3배 + 바깥으로 퍼지는 링 2겹 | 지금 보고 있는 곳 |

> 마커의 **클릭 영역은 34×34px**입니다. 보이는 점은 16px이지만, 그 크기 그대로 누르게 하면
> 지도 위에서 조준이 어려워 클릭이 자주 빗나갑니다. 투명한 히트박스(`.pin-hit`) 안에 점을 가운데
> 두어 겉보기는 그대로 두고 누를 수 있는 면적만 넓혔습니다. hover 반응과 키보드 포커스 링도
> 히트박스가 아니라 점을 기준으로 그립니다.

> 검색 핀을 점선으로 둔 이유: 색으로 구분하면 팔레트에 색이 하나 더 늘어납니다.
> 같은 색을 쓰되 **채움 여부와 선의 종류**로 구분하면 톤을 유지한 채 "임시로 얹힌 것"이라는 성격이 드러납니다.

## 6. 상세 카드

지도 좌하단에 떠 있는 폭 300px 카드. (좁은 화면에서는 지도 아래로 내려갑니다)

```
장소명  [검색한 위치]      ← 검색 핀일 때만 점선 배지
국가 · 지역
[아이콘 40px]  21°         ← 기온이 카드에서 가장 큰 요소
맑음 · 현지 낮
─────────────────
체감    습도    바람        ← 3열 그리드, 작은 라벨 + 값
```

- 날씨 아이콘은 인라인 SVG 6종(해·달·구름·비·눈·뇌우), 선 굵기 1.6px, `currentColor`
- **맑음만 낮/밤 아이콘이 다릅니다**(해/달). 나머지는 낮이든 밤이든 같은 아이콘을 쓰고, 낮·밤은 배경과 텍스트가 알려줍니다

## 7. 로딩과 에러

| 상태 | 모양 |
|---|---|
| 초기 일괄 로딩 | 리스트 자리에 항목 크기의 스켈레톤 12개 (좌→우로 흐르는 shimmer) |
| 장소 선택 후 | 상세 카드 **위에만** 반투명 오버레이 + 스피너. 지도·리스트·배경은 그대로 |
| 에러 | 해당 영역에 한 줄 메시지 + 테라코타 재시도 버튼 |
| 필터 결과 0개 | 에러가 아니라 빈 상태. 중앙 정렬 보조 텍스트 |

> 전체 화면을 덮는 에러 화면은 만들지 않습니다. 날씨를 못 불러와도 지도를 돌려보는 것은 계속 됩니다.

## 8. 모션

허브의 "애니메이션은 최소한으로" 원칙을 따릅니다.

| 대상 | 값 |
|---|---|
| 배경 전환 | opacity 0.6s ease |
| 지도 이동 | `flyTo` 0.9s |
| hover(카드·칩·마커) | 0.2s ease |
| 스피너 | 0.8s 회전 |

`prefers-reduced-motion: reduce`에서는 배경 전환·shimmer·마커 확대가 모두 멎고,
지도 이동도 애니메이션 없이 즉시 이동(`setView`)으로 바뀝니다.
