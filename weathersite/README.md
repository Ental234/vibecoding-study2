# 지금, 그곳

**세계 랜드마크를 지도에서 고르면, 그 장소의 지금 날씨가 배경째로 바뀌는 사이트.**

날씨 정보는 어디서든 볼 수 있지만 대개 숫자 몇 줄입니다. 여기서는 에펠탑을 누르면 파리의
현재 기온과 함께 **배경이 파리의 지금(맑음/밤, 비/낮 …)으로 바뀝니다.** 정보를 읽는 것에서
그 장소의 공기를 잠깐 느끼는 쪽으로 옮겨보는 것이 목표입니다.

Project Hub에 등록되는 사이드 프로젝트이며, 허브와 같은 방식(순수 HTML/CSS/JS, 빌드 없음)으로 만들었습니다.

---

## 실행

```bash
git clone <repo>
cd weathersite
# index.html 을 브라우저로 열면 끝입니다 (서버·빌드·설치 없음)
```

지도 타일과 날씨 API를 불러오므로 **인터넷 연결은 필요합니다.**

## 무엇이 되나

| 기능 | 내용 |
|---|---|
| 지도 & 마커 | 대륙별 랜드마크 12곳을 지도에 표시. 마커를 누르면 그곳의 현재 날씨 조회 |
| 사이드패널 리스트 | 지도와 양방향 연동. 리스트를 누르면 지도가 이동하고, 마커를 누르면 리스트가 하이라이트됨. 각 항목에 현재 기온과 날씨 아이콘 표시 |
| 도시 검색 | 전 세계 아무 도시나 검색. 고르면 지도가 이동하고 **점선 핀**으로 표시됨 (랜드마크와 구분) |
| 필터 | 지역(대륙) · 날씨 상태 · 기온 범위를 동시에(AND) 적용. 지도 마커와 리스트에 함께 반영 |
| 배경 전환 | 날씨 5종 × 낮/밤 = **10종 배경**이 선택에 따라 0.6초 교차 전환 |

## 무엇이 안 되나 (v1 범위 밖)

- 시간별·주간 예보 (현재 날씨만)
- 즐겨찾기·검색 위치 저장 (새로고침하면 사라집니다)
- 아침/저녁 등 4단계 이상 시간대 배경 (지금은 낮/밤 2단계)
- 다국어

## 사용한 API (둘 다 무료, 키 불필요)

| API | 용도 |
|---|---|
| [Open-Meteo Forecast](https://open-meteo.com/) | 기온, 체감, 습도, 풍속, weather_code, is_day |
| [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) | 도시 검색과 좌표 변환 |

> 랜드마크 12곳의 날씨는 **요청 한 번**으로 받아옵니다. Open-Meteo는 `latitude=a,b,c` 처럼 좌표를
> 콤마로 이어 붙이면 결과를 배열로 돌려줍니다. 12번 호출할 필요가 없습니다.

> 도시 검색은 Open-Meteo의 색인이 로마자 기준이라 **영문 이름이 가장 잘 맞습니다.**
> (`Seoul` → 서울특별시 · 대한민국 으로 한글 표기되어 나옵니다. 한글로 입력하면 도시에 따라 결과가 없을 수 있습니다.)

지도는 [Leaflet](https://leafletjs.com/) + CARTO Dark Matter 타일을 CDN으로 씁니다.

## 파일 구조

```
weathersite/
├── index.html          화면 골격
├── style.css           디자인 토큰 + 레이아웃 + 배경 테마 10종
├── app.js              상태 · API · 렌더 · 지도 · 필터 · 검색
├── data/
│   └── landmarks.js    랜드마크 12곳 (여기에 항목만 추가하면 지도·리스트·필터가 자동으로 늘어남)
├── DESIGN.md           색·타이포·배경 테마 규칙
└── PRD.md              기획 문서
```

랜드마크를 추가하려면 `data/landmarks.js`에 `{ id, name, country, continent, lat, lng }` 한 줄을 넣으면 됩니다.
`continent`는 `asia / europe / north-america / south-america / africa / oceania` 중 하나여야 지역 필터에 잡힙니다.

## 접근성

- 리스트·필터·검색 결과가 모두 버튼이라 키보드만으로 조작할 수 있습니다 (검색은 ↑/↓/Enter/Esc)
- 상세 카드는 `aria-live="polite"` — 날씨가 바뀌면 스크린 리더가 읽어줍니다
- 포인트 색 위에는 흰 글씨를 쓰지 않습니다 (DESIGN.md §2)
- `prefers-reduced-motion`을 켜면 배경 전환·지도 이동 애니메이션이 멎습니다
